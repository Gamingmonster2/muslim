## 📌 ملاحظات للمستقبل

- **الترميز**: لا تُعدّل ملفات المشروع بأدوات PowerShell النصية (`Get-Content`/`Set-Content`) لأنها تفسد النص العربي. استخدم أدوات التحرير التي تحفظ UTF-8، أو Node مباشرة.
- **الصوت**: إن تغيّرت روابط tvQuran مستقبلًا، حدّث `src/features/ruqyah/data/sheikhs.ts` فقط.
- **النسخ الاحتياطي للصوت**: يمكن إضافة نسخة archive.org للشيخ سعود (عنصر `RuqiaShariaSaudAlFayez`) كرابط بديل.
- **الهوية البصرية**: كل الألوان في متغيّرات `:root` داخل `src/styles/index.css` — تُستبدل بسهولة عند وصول نظام التصميم النهائي.
