# خطة بناء منصة «اسمع دينك» — تطبيق الرقية الشرعية

> **المستودع:** `Gamingmonster2/muslim` · **النطاق:** `muslim.com.ly` · **النشر:** Cloudflare Pages
> **الهدف:** منصة إسلامية احترافية ثنائية اللغة (عربي/إنجليزي) تبدأ بتطبيق الرقية الشرعية، وتضم الأذكار والمسبحة ومكتبة صوتية منتقاة من القرآن الكريم والسنة النبوية.

---

## 1. المشكلة الحالية (تشخيص الكود القديم)

### أ) تطبيق الرقية (`Ruqyah Shar'iyyah.txt`)

| المشكلة | السبب التقني | الحل |
|---|---|---|
| الصوت يشتغل مع بعض (تداخل شيخين) | إطاران `<iframe>` لموقع خارجي يُحمَّلان معاً، وإخفاء الإطار بـ`display:none` لا يوقف التشغيل | مشغّل صوت واحد HTML5، وملفات MP3 مباشرة، ولا يوجد إطاران أصلاً |
| التسميات مقلوبة | `author/212` = عصام العويد و`author/121` = سعود الفايز، والكود يضع 212 لبطاقة «سعود» و121 لبطاقة «عصام» | بيانات مصححة من المصدر مع تحقق آلي |
| لا تحكم كامل بالمشغل | المشغل مملوك لموقع خارجي (tvquran) داخل iframe | مشغل مخصص: تقديم/تأخير، سرعة، مؤقت نوم، تكرار، قائمة انتظار، Media Session |
| لا نبذة ولا صور فعلية للشيوخ | بطاقات بأيقونات صوت عامة | صور الشيوخ الرسمية + نبذة مكتوبة + إحصاءات استماع |
| لا يعمل دون اتصال ولا يُثبَّت كتطبيق | لا PWA ولا manifest حقيقي | PWA كامل + Service Worker + شاشة تثبيت |

### ب) موقع المكتبة (`muslim.com.ly.txt`)

| المشكلة | الحل |
|---|---|
| يعتمد كلياً على `archive.org` في وقت التشغيل (بحث عشوائي، نتائج مختلطة تحتوي أذان/أناشيد/شعر) | **خط إنتاج محتوى منتقى يدوياً** يُبنى وقت النشر إلى ملفات JSON ثابتة، فلا استعلام عشوائي في المتصفح |
| إطارات embed ثقيلة وبطيئة | روابط MP3 مباشرة + مشغلنا الموحد |
| Tailwind CDN + FontAwesome CDN (بطيء، لا يعمل بلا إنترنت) | Tailwind v4 مبنية + أيقونات `lucide-react` محلية |
| تصميم غير متسق | نظام تصميم shadcn/ui مع رموز ألوان وخطوط موحدة |
| خلط محتوى غير ديني | قائمة انتقاء يدوية: مصاحف كاملة + شروح حديث فقط |

## 2. التقنية (Stack)

- **Next.js (App Router) + TypeScript** — تصدير ثابت `output: "export"` (لا خادم، أسرع وأرخص على Cloudflare Pages).
- **Tailwind CSS v4 + shadcn/ui** — نفس لغة تصميم مستودع `shadcn-ui/ui` (CSS variables، مكوّنات Radix، نصف قطر، حدود ناعمة).
- **next-themes** — فتح/إغلاق الوضع الليلي.
- **lucide-react** — أيقونات.
- **خطوط:** `IBM Plex Sans Arabic` للواجهة، `Amiri`/`Scheherazade New` لنصوص القرآن والأذكار.
- **بدون قاعدة بيانات ولا حساب مستخدم:** التفضيلات وتقدّم الاستماع في `localStorage`.

## 3. تجربة المستخدم (Information Architecture)

```
/                الرئيسية (عربي)          /en              Home (English)
/ruqyah          الرقية الشرعية            /en/ruqyah
/scholars        الشيوخ                     /en/scholars
/scholars/[id]   صفحة الشيخ (نبذة+تسجيلات)  /en/scholars/[id]
/adhkar          الأذكار                    /en/adhkar
/adhkar/[id]     أذكار الصباح/المساء…       /en/adhkar/[id]
/tasbeeh         المسبحة الإلكترونية        /en/tasbeeh
/library         المكتبة الصوتية (قرآن/حديث) /en/library
/library/[id]    تفاصيل مصحف/شرح حديث       /en/library/[id]
/about           عن المنصة وصدقة جارية       /en/about
```

- العربية هي الافتراضية (RTL). الإنجليزية بمسار `/en` وLTR. `hreflang` + `canonical` لكل صفحة.
- **مبدّل لغة وفوري** في الترويسة، محفوظ في `localStorage`.

### الصفحة الرئيسية — الأقسام بالترتيب

1. **Hero:** اسم المنصة + جملة «شفاء ورحمة» + زر «استمع الآن» (يشغّل رقية الشيخ المميز فوراً ويفتح المشغل).
2. **بطاقة الشيخ المميز** (عصام العويد): صورة، نبذة سطرين، مدة التسجيل، زر تشغيل كبير، وشريط تقدّم يعود لآخر موضع استماع.
3. **الشيوخ الآخرون:** شبكة بطاقات «يمكنك الاستماع أيضاً» من تصنيف الرقية (سعود الفايز أولاً ثم المشهورون).
4. **أدوات سريعة:** الأذكار / المسبحة / الرقية الذاتية (نصوص تُقرأ).
5. **من المكتبة:** عيّنة من المصاحف والشروح مع زر «تصفّح المكتبة».
6. **صدقة جارية** في التذييل + «رحم الله سيف الدين».

### صفحة الشيخ `/scholars/[id]`

- غلاف بالصورة + الاسم + نبذة + إحصاءات (استماع/إعجاب) + زر «تشغيل الكل».
- قائمة التسجيلات (الرقية الشرعية وتمييزها، ثم تلاوات أخرى إن وُجدت).
- قسم «قد يعجبك»: 4 شيوخ آخرين من نفس التصنيف.

### المكتبة `/library`

- تبويبات: **المصاحف الكاملة** / **صحيح السنة وشروحها**.
- فلترة: القارئ/الشيخ، البحث النصي، ترتيب (الأكثر استماعاً/الأحدث).
- بطاقة لكل مصحف: الغلاف، القارئ، عدد التلاوات، مدة تقريبية، زر تشغيل القائمة.
- صفحة التفاصيل: كل السور/الدروس كقائمة قابلة للتشغيل مع تمييز «المستمع الآن».

### الأذكار `/adhkar`

- تصنيفات: الصباح، المساء، النوم، الاستيقاظ، الهمّ والحزن، الرقية الذاتية (آيات وسور).
- صفحة قراءة هادئة: النص بخط عربي كبير، عدّاد لكل ذكر مع حلقة تقدّم، إنجاز محفوظ محلياً، «أكملت» تُخفّي التذكير.
- النصوص مدققة ومصححة، مع مراجع (آية/حديث) حيث أمكن.

### المسبحة `/tasbeeh`

- عدّاد كبير + اهتزاز + صوت خفيف (اختياري) + أهداف (33/99/100) + حفظ تراكمي يومي + تصفير مع تأكيد.
- أذكار جاهزة للتبديل بلمسة.

## 4. محرك الصوت (قلب التطبيق)

**فلسفة:** عنصر `<audio>` واحد في التطبيق كله؛ لا يوجد أي طريقة مادية لتداخل صوتين.

- **مصدر واحد** داخل `AudioProvider` (React Context): `playQueue/playTrack/pause/toggle/next/prev/seek/setVolume/setRate/sleepTimer`.
- **قائمة انتظار + قائمة السياق** (مصحف كامل، تسجيلات شيخ، مكتبة).
- **حالات:** تكرار (بدون/مقطع/قائمة)، عشوائي، تقديم/تأخير ١٠/٣٠ث.
- **مؤقت نوم:** ١٥/٣٠/٤٥/٦٠ دقيقة أو نهاية المقطع، مع تلاشي تدريجي للصوت.
- **استئناف:** موضع كل مقطع محفوظ ويعود إليه المستخدم عند الفتح («متابعة الاستماع»).
- **Media Session API:** تحكم من شاشة القفل/سماعات البلوتوث بالأغلفة والعناوين.
- **إعادة المحاولة** تلقائياً عند فشل الشبكة + رسالة واضحة بدل الصمت.
- **لوحة مصغّرة ثابتة** أسفل الشاشة + مشغّل كامل (Sheet) بتصميم غلاف دائري وتدرّجات.
- **تنزيل المقطع** (رابط مباشر) و**مشاركة** بضغطة.
- **المفضلة + سجل الاستماع** محلياً.

## 5. المحتوى: خط الإنتاج (Content Pipeline)

### أ) الرقية والشيوخ — من `tvquran.com`

1. كشط صفحة التصنيف `category/6` (الرقية الشرعية) بكل صفحاتها (٢٠ عنصر/صفحة، ترتيب حسب الأكثر استماعاً).
2. لكل عنصر: العنوان، المؤلف (رقم/اسم/رابط)، رابط الصوت `download.tvquran.com/...mp3`، عدد الاستماع والإعجاب، صورة الشيخ.
3. لكل شيخ مميز: كشط صفحة الملف الشخصي لاستخراج **النبذة** (مثل نبذة الشيخ عصام)؛ ومن لا نبذة له تُكتب نبذة مختصرة موثقة من مصادر علنية.
4. تنزيل الصور محلياً في `public/images/scholars/` (‏cache-busting باسم الملف).
5. تحقق آلي: `HEAD` لكل MP3 (يجب `200` + `audio/mpeg`) + حجم + `Accept-Ranges`؛ أي رابط فاشل يُستبعد ويُبلَّغ عنه.
6. ترتيب الأسماء العربية/الإنجليزية يدوياً في ملف ترجمة صغير داخل السكربت.
7. الناتج: `src/content/scholars.json`.

**الترتيب المعتمد:** الشيخ عصام العويد أولاً (المميز)، ثم سعود الفايز، ثم بقية شيوخ الرقية المشهورين.

### ب) المكتبة — من `archive.org`

1. ملف انتقاء يدوي `scripts/curation.json` يحتوي معرّفات archive.org فقط للأعمال الموثوقة:
   - **مصاحف كاملة:** (نماذج) مشاري العفاسي، ماهر المعيقلي، عبد الباسط (مرتل/مجود)، المنشاوي (المعلم)، الحصري (مرتل/معلم)، سعد الغامدي، ياسر الدوسري، فارس عباد، أحمد العجمي، الحذيفي، السديس والشريم، إدريس أبكر، وديع اليمني، عمار الملا، الشاطري…
   - **سنة وشروح:** صحيح البخاري (قراءة صوتية)، صحيح مسلم، رياض الصالحين (شرح ابن عثيمين/ابن باز)، شروح الشيخ عبد المحسن العباد…
2. لكل معرّف: `archive.org/metadata/{id}` → اختيار ملفات MP3 (وملف الغلاف)، والتحقق من صحة الروابط.
3. استخراج المدة من حقول الملفات، وتجميع المسارات بترتيب السور/الدروس.
4. استبعاد أي مادة: أناشيد، شعر، موسيقى، سياسة، أو غير متعلقة بالقرآن والسنة.
5. الناتج: `src/content/library.json` + أغلفة في `public/images/library/`.

### ج) الأذكار والرقية الذاتية

- ملفات TypeScript مكتوبة يدوياً: `src/content/adhkar/{ar,en}.ts`.
- مراجعة النصوص وتصحيح الأخطاء الموجودة في النسخة القديمة (مثل تكرار «وَلَمْ يُولَدْ» في سورة الإخلاص).
- لكل ذكر: النص العربي، المصدر/المرجع، العدد، ترجمة إنجليزية للمعنى.

### د) تحديث المحتوى

- GitHub Action أسبوعي يشغّل سكربتات المحتوى ويفتح Commit تلقائياً إذا تغيّر شيء (اختياري بعد الاستقرار).
- `npm run content:validate` يفحص كل الروابط قبل النشر.

## 6. نظام التصميم (شكل shadcn/ui)

**الاتجاه:** نظيف وعصري بهوية إسلامية هادئة — مساحات بيضاء، حدود ناعمة، حلقات تركيز دقيقة، حركات قصيرة، وألوان مستوحاة من الزمرد والذهب.

- **الأساس:** مكوّنات shadcn/ui (Button, Card, Dialog, Sheet, Tabs, Badge, Slider, Progress, Dropdown, Accordion, Sonner…).
- **اللوحة:**
  - Light: خلفية عاجية دافئة `#FAFAF7`، بطاقات بيضاء، **زمردي** أساسي `#0F6B4F`، **ذهبي** للتمييز `#C9A227`، نص `#17211C`.
  - Dark: خلفية `#0B1512`، بطاقات `#111F1A`، زمردي فاتح `#3DBE8B`، ذهبي دافئ.
- **الخطوط:** IBM Plex Sans Arabic (واجهة) + Amiri (عناوين قرآنية وأذكار).
- **الأشكال:** `radius: 1rem` موحد، ظلال ناعمة جداً، زخرفة هندسية SVG خفيفة جداً في الهيرو.
- **RTL أولاً:** كل الفراغات والاتجاهات منطقية `start/end` لا `left/right`.
- **الوصولية:** تباين AA، تنقل بلوحة المفاتيح، `aria` لكل عنصر تحكم، احترام `prefers-reduced-motion`.
- **الجوال أولاً:** المشغل مصمم للإصبع، أهداف لمس ≥ 44px.

## 7. الأداء وPWA

- تصدير ثابت: HTML جاهز لكل مسار، تحميل أولي خفيف، صور بأحجام مضبوطة (`next/image` مع `unoptimized` للتصدير الثابت لكن مقاسات ثابتة).
- `preconnect` لخادم الصوت، `preload="metadata"` فقط، تشغيل عند الطلب.
- PWA: manifest كامل (RTL، أيقونات 192/512/maskable)، Service Worker يخزن الهيكل وHTML والأذكار (غير المتغيرات) للعمل دون اتصال، مع صفحة احتياطية offline.
- زر «ثبّت التطبيق» ذكي (يظهر عند توفر `beforeinstallprompt`، ويشرح يدوياً على iOS).
- هدف Lighthouse: Performance ≥ 90، Accessibility ≥ 95 على الجوال بعد البناء.

## 8. النشر على Cloudflare Pages

1. المستودع `Gamingmonster2/muslim` (فرع `main`) هو مصدر البناء.
2. في لوحة Cloudflare: Workers & Pages → Create → Pages → Connect to Git → المستودع.
   - Framework preset: **Next.js (Static HTML Export)**
   - Build command: `npm run build`
   - Build output directory: `out`
   - Node version: 20/22 (متغير `NODE_VERSION=22`)
3. ملفات مساندة: `public/_headers` (تخزين مؤقت للصور/الأصول) و`public/_redirects` عند الحاجة.
4. ربط النطاق المخصص `muslim.com.ly` + `www` (Cloudflare DNS) وإجبار HTTPS.
5. بعد الربط: تفعيل الـ Deployment تلقائياً عند كل `git push` إلى `main`.
6. GH Action اختياري: تحديث المحتوى الدوري.

## 9. الجودة والاختبارات

- `npm run build` يجب أن ينجح بلا أخطاء TypeScript.
- `npm run content:validate` فحص كل روابط الصوت (HTTP 200 + نوع صوتي).
- فحص يدوي/آلي: تنقل RTL/LTR، تبديل اللغة، الوضع الليلي، تشغيل/إيقاف/تقديم، الموبايل.
- فحص عدم وجود نص مقطوع أو ترجمة ناقصة (سكربت `check-i18n` يضمن تساوي مفاتيح ar/en).
- التحقق من `sitemap.xml` و`robots.txt` و`hreflang` بعد البناء.

## 11. المخاطر وخطط البديل

| الخطر | الاحتمال | البديل |
|---|---|---|
| حجب الساخنة لملفات tvquran (hotlink) | منخفض — اختُبر ويعمل من أي Referer | وسيط Cloudflare Worker بروابط موقعة + تخزين مؤقت |

## 12. ما بعد الإطلاق (خارطة طريق)

- إضافة تطبيقات المنصة الأخرى (مواقيت الصلاة، القبلة، المصحف المكتوب، الأحاديث اليومية).
- جودات صوت متعددة ووضع «تحميل للاستماع دون اتصال».
- مفضلة ومزامنة اختيارية (حساب خفيف) إن رغبت لاحقاً.
- إحصائيات استماع مجهولة لتحسين الترتيب.
